# Sanchaar Setu

Sanchaar Setu is a comprehensive communication and audit platform.

## Architecture

- **Backend**: FastAPI with a multi-layered ingestion and processing engine.
- **Frontend**: React-based dashboard for conflict review and audit logs.
- **Infra**: Docker-managed services including Kafka, Redis, and Postgres.

## Directory Structure

- `backend/`: API and core logic.
- `frontend/`: Dashboard and user interfaces.
- `infra/`: Infrastructure configuration and deployment scripts.
